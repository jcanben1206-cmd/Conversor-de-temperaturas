# Conversor-de-temperaturas

## Ejecución

Compila las clases:

```bash
javac CelsiusAFahrenheit.java FahrenheitACelsius.java ConversorTemperaturas.java
```

Ejecuta el programa principal:

```bash
java ConversorTemperaturas
```

El programa solicita una temperatura en Fahrenheit y otra en Celsius, y muestra ambas conversiones.
